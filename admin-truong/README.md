# Admin trường

Admin trường quản lý toàn bộ danh sách người dùng (sinh viên FTU, giảng viên, sinh viên ngoại quốc) trên hệ thống FTU Smart Campus.

* [Quản lý người dùng](quan-ly-nguoi-dung.md) — xem, sửa hồ sơ và gắn/thu hồi thẻ NFC.
* [Import danh sách](import-danh-sach.md) — thêm nhiều người dùng cùng lúc từ file Excel.
* [Xóa người dùng](xoa-nguoi-dung.md) — xóa đơn lẻ hoặc xóa hàng loạt.

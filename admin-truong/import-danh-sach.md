# Import danh sách

Admin trường có thể thêm nhiều người dùng cùng lúc bằng cách import từ file Excel, thay vì tạo thủ công từng người.

## Các bước import

1. Bấm **Import Excel** và chọn tệp danh sách người dùng.

<div data-with-frame="true"><img src="../.gitbook/assets/ad03-image4.png" alt="Chọn tệp Excel để import" width="480"></div>

{% hint style="warning" %}
Tệp danh sách phải đúng theo **Template mẫu** quy định. Tải template về trước khi chuẩn bị dữ liệu để import.
{% endhint %}

2. Kiểm tra bản xem trước dữ liệu mà hệ thống hiển thị, rà soát kỹ trước khi xác nhận nhập.

<div data-with-frame="true"><img src="../.gitbook/assets/ad03-image5.jpg" alt="Kiểm tra bản xem trước dữ liệu" width="480"></div>

3. Xác nhận để hoàn tất import danh sách.

<div data-with-frame="true"><img src="../.gitbook/assets/ad03-image6.jpg" alt="Import danh sách thành công" width="480"></div>

## Lưu ý

* Luôn dùng đúng template mẫu để tránh lỗi sai cột hoặc thiếu trường dữ liệu bắt buộc.
* Kiểm tra kỹ bản xem trước — sau khi xác nhận, dữ liệu sẽ được nhập trực tiếp vào hệ thống.
* Với người dùng đã tồn tại (trùng MSSV/email), cần xác định trước quy tắc cập nhật hay bỏ qua để tránh tạo trùng hồ sơ.
